# 成語小達人 🐰📚

給小朋友複習成語的手機網頁遊戲。所有文字都有注音（台灣教育部標準讀音）。

## 遊戲內容

| 模式 | 玩法 | 練習什麼 |
|---|---|---|
| 📚 學習卡 | 成語、意思、故事、例句，可以按 🔊 唸出來 | 認識成語 |
| 🔗 連連看 | 成語配對簡短意思 | 理解意思 |
| ✏️ 例句填空 | 句子裡挖空，選正確的成語 | **怎麼應用** |
| 🧩 缺字補補 | 成語少一個字，選出來 | 記住寫法 |
| 🔀 排排看 | 打亂的字依序排好 | 記住寫法 |
| 💡 猜成語 | 看完整意思選成語 | 理解意思 |
| 🏆 今日挑戰 | 上面各種題型混合 | 綜合複習 |

- 答錯的成語、最新學的成語會比較常出現。
- 答完會列出答錯的成語，方便再複習。
- 答題紀錄和星星存在手機裡。

## ➕ 新增成語（不用改程式）

編輯 `data/idioms.json`，在 `idioms` 陣列最後面加一筆（**最後一筆就是首頁的「今日成語」**）：

```json
{
  "idiom": "對牛彈琴",
  "emoji": "🐮🎵",
  "short": "說話不看對象",
  "meaning": "比喻說話不看對象，對不懂道理的人講道理。",
  "story": "古時候有一位音樂家……",
  "source": "《理惑論》",
  "examples": [
    "跟弟弟講股票的事，簡直是對牛彈琴。"
  ],
  "related": []
}
```

| 欄位 | 必填 | 說明 |
|---|---|---|
| `idiom` | ✅ | 成語 |
| `meaning` | ✅ | 意思 |
| `short` | 建議 | 10 字內的簡短意思，連連看、提示用 |
| `examples` | 建議 | 例句，**句子裡要包含這個成語**才能出填空題 |
| `emoji` / `story` / `source` | | 圖案、故事、出處 |
| `related` | | 意思很像的成語（如「一飛衝天」和「一鳴驚人」），填空題不會同時出現當選項 |

在手機上也能改：GitHub App 或網頁打開 `data/idioms.json` → 鉛筆圖示編輯 → Commit。網站約一分鐘後自動更新。

> 也可以在遊戲裡的「家長區」直接新增（只存在那支手機），之後按「複製 JSON」貼進 `idioms.json` 永久保存。

### 注音唸錯怎麼辦？

注音是自動產生的，常見破音字已處理。如果某個字讀音不對，在那個字後面加 `[注音]`：

```
"他的田卻長[ㄓㄤˇ]滿了野草。"
```

檢查方法：家長區的「注音檢查」輸入文字即可預覽，會列出句中的破音字；或在電腦執行 `node tools/check-zhuyin.js` 列出所有內容的破音字讀音。

## 🚀 放上網路（GitHub Pages，免費）

1. 把這個分支合併到 `main`
2. GitHub 專案 → **Settings → Pages** → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)` → Save
3. 約一分鐘後網址會是 `https://<帳號>.github.io/Kobesula/`
4. 用手機打開 → Safari「分享 → 加入主畫面」（Android Chrome「加到主畫面」），就像 App 一樣，離線也能玩

> 注意：私人（private）repo 使用 GitHub Pages 需要付費方案；免費帳號請把 repo 設成 public。

## 檔案結構

```
index.html            頁面
css/style.css         樣式
js/app.js             遊戲邏輯
js/zhuyin.js          注音引擎（詞語比對處理破音字 + [ ] 手動指定）
data/idioms.json      ★ 成語資料（新增成語只改這裡）
data/zhuyin.json      注音字典（由教育部《重編國語辭典修訂本》整理）
tools/build_dict.py   重建注音字典（調整破音字預設讀音時才需要）
tools/check-zhuyin.js 檢查所有內容的破音字讀音
sw.js                 離線快取
```

本機測試：在專案資料夾執行 `python3 -m http.server`，打開 http://localhost:8000 。
